A one-star review written by a house cat about its human, in one line under 200 characters. The program writes the review to `/output/entry.txt`.

> One star. He bought me a $60 bed. I sleep in the box it came in. He spent $60 learning nothing.

## Run it

```sh
python3 main.py
```

The review is written to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set, for local checks).
